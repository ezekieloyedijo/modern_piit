Free tech skills training for Lagos residents

PIIT, in partnership with the Lagos State Employment Trust Fund (LSETF), is opening applications for a fully-funded digital skills programme across two in-demand tracks.

Two in-demand tracks, one fully-funded programme

Track 1

Cybersecurity

12 Weeks · Hybrid

Apply core cybersecurity practices to identify risks, secure systems, and support incident response.

  • Cybersecurity Fundamentals
  • Defensive Security
  • Ethical Hacking
  • Security+ & SOC Analyst Skills
Track 2

Software Development (Full Stack)

20 Weeks · Hybrid

Develop and deploy functional web or mobile applications using modern software development technologies.

  • Full-Stack Web Development
  • Backend Development
  • Mobile Development
  • Python & MERN Stack
Good to Know

Programme Details

Class format

Hybrid delivery — physical classes hold twice a week, with the remaining sessions online.

Who can apply

  • Resident in Lagos State, with a valid LASRRA (Lagos State Residents Registration Agency) card
  • Willing and available to attend physical classes twice weekly
  • Age: 18–35 years
  • Open to applicants seeking an internship placement

Cost

Completely free — training is fully sponsored by the Lagos State Government through LSETF.

Duration & certification

  • Software Development (Full Stack): 20 weeks, hybrid
  • Cybersecurity: 12 weeks, hybrid
  • Certificate of completion awarded at the end of the programme

Class locations

Training venue: Amazing Grace Mall, Lakowe Lekki Epe Road, Lagos.

Application deadline

  • Programme launch / applications open — Friday, 18th September 2026
  • Application window closes — 2nd October 2026
  • Training commences from — 7th October 2026
