🚀 FASTEST WAY TO GET STARTED (5 STEPS)
════════════════════════════════════════════════════════════════════════════

STEP 1: Edit config.php (2 minutes)
────────────────────────────────────────────────────────────────────────────
Find and update these lines:

OLD:
    define('DB_HOST', 'localhost');
    define('DB_USER', 'root');
    define('DB_PASS', '');

→ Change to your cPanel MySQL credentials

OLD:
    define('ADMIN_USERNAME', 'admin');
    define('ADMIN_PASSWORD', 'PIIT@2024Secure');

→ Change to your desired username/password

STEP 2: Create Database in cPanel (3 minutes)
────────────────────────────────────────────────────────────────────────────
1. Log into cPanel
2. Go to: MySQL Databases
3. Create database: piit_certificates
4. Create user with strong password
5. Add user to database with ALL privileges

STEP 3: Upload Files via cPanel (5 minutes)
────────────────────────────────────────────────────────────────────────────
Upload these files to your website root:
✓ config.php
✓ db_connect.php
✓ init_db.php
✓ admin-login.php
✓ admin-dashboard.php
✓ admin-logout.php
✓ api-upload.php
✓ api-search.php
✓ certificate-query.html
✓ assets/css/module-css/certificate-query.css (upload to subdirectory)

STEP 4: Initialize Database (1 minute)
────────────────────────────────────────────────────────────────────────────
1. Open browser: https://yoursite.com/init_db.php
2. You should see green success messages
3. DELETE init_db.php immediately after!

STEP 5: Test Everything (2 minutes)
────────────────────────────────────────────────────────────────────────────
✓ Login: https://yoursite.com/admin-login.php
✓ Upload test certificate
✓ Search: https://yoursite.com/certificate-query.html
✓ Download test

DONE! ✅

🔧 CONFIGURATION FILE LOCATIONS & CHANGES
════════════════════════════════════════════════════════════════════════════

File: config.php (MAIN CONFIGURATION FILE)
Location: Website root directory

Key Settings to Update:

Line 5-7:   Database connection (REQUIRED)
            define('DB_HOST', 'localhost');
            define('DB_USER', 'your_username');
            define('DB_PASS', 'your_password');

Line 8:     Database name
            define('DB_NAME', 'piit_certificates');

Line 11-12: File upload settings
            define('MAX_FILE_SIZE', 50 * 1024 * 1024);
            define('ALLOWED_TYPES', ['jpg', 'jpeg', ...]);

Line 16-17: Admin credentials (CHANGE THESE!)
            define('ADMIN_USERNAME', 'admin');
            define('ADMIN_PASSWORD', 'PIIT@2024Secure');

Line 18:    Session timeout (in seconds)
            define('SESSION_TIMEOUT', 3600);

ALL OTHER FILES: Do not modify unless you know PHP!

❓ MOST COMMON ISSUES & FIXES
════════════════════════════════════════════════════════════════════════════

❌ "Connection failed" error
✅ Check config.php - verify DB_USER and DB_PASS match cPanel credentials

❌ Upload button doesn't work
✅ Ensure /certificates/ folder exists and has 755 permissions
✅ Check MAX_FILE_SIZE doesn't exceed cPanel upload limit

❌ Search returns nothing
✅ Verify certificates were actually uploaded
✅ Check database connection is working

❌ Can't login
✅ Verify username/password in config.php
✅ Clear browser cache and try again
✅ Check that cookies are enabled

❌ File won't delete
✅ Check /certificates/ folder permissions
✅ Verify MySQL user has DELETE privilege
✅ Try manual deletion via cPanel File Manager
